# 粒子シミュレーションのアニメーション

## 概要

[rod_simulation.md](rod_simulation.md) に基づく、既存のコードベースによるシミュレーションと同様に粒子の動作を演算し、その動きを表示するようなアニメーションを作成してください。

## 画面とアニメーションの要件

egui(0.34.3) を用いて、以下の要件を満たすアニメーションを作成してください。

- 水路の形状と棒状粒子を描画する
- アニメーションの速度は、実験で観察される時間スケールに合わせる（例：1秒間のアニメーションが実験の1秒に相当するように）
  - ただし、シミュレーションの計算時間が長くなるとか、極度に難しいとか、画面が書くついてしまうという場合には、アニメーションの速度を調整しても構いません
- ユーザーがアニメーションを開始、停止、リセットできるようにする
- 次のパラメータが変更可能
  - シード値
  - 棒の長さ（代表点の数）
  - x軸方向に粒子全体へ一定にかかっている合力 $f$
  - 粒子の電気的な性質
    - `βqE`: -5から5の範囲
    - `ΔαE/(ql)`: -5から5の範囲
