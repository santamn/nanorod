# 仕様書

## タスク

Rust + CUDA + cudarc を使用して[rod_simulation.md](./rod_simulation.md) の内容をもとに、GPUを使用して効率的に数値シミュレーションを行い、[./rod_simulation.md](./rod_simulation.md) に書かれてある数値をファイルに出力するプログラムを作成してください。利用できるリソースについては[architecture.md](./architecture.md)を参照してください。

## 注意事項

- 関数や一定の複雑さをもつコード片には、日本語でわかりやすいコメントをつけてください
- 過剰なフォールバックを避けてください。最悪GPUが壊れなければ大丈夫です。
- 可能な限り、コードはシンプルで効率的にしてください。冗長なコードや非効率なアルゴリズムは避けてください。
- GPUを効率的に活用し、高速に計算が行われるようにしてください。
- 使用するライブラリは最新のものがないか確認し、最新のものを使うようにしてください
- 必要であればネット上のドキュメントやベストプラクティスを参照して、最適な実装を行ってください。
